# UI kit — Wear OS

Three round tiles, always dark: **Next up** (one action, nothing else),
**Urgent alert** (the Ack button is the whole point — swiping a notification
away is not an ack) and **Calendar context** (honestly stale rather than
absent).

Rules for the wrist: one answer per tile, no lists longer than three rows,
44px minimum tap target, and only `urgent`-tier deliveries reach it by
default. No Wear client exists in the repository yet — proposed, from
`CONTEXT.md` and ADR-0012.
