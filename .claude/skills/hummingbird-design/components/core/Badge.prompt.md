A small pill for labels, counts and states that are not the item's stage (stage has its own component).

```jsx
<Badge tone="warn" icon="clock">Due today</Badge>
<Badge mono tone="neutral">SIZE:DEEP</Badge>
<Badge tone="danger" dot>Overdue</Badge>
```

Use `mono` for machine-ish values (labels, sizes, "as of" times), the sans default for human words.
